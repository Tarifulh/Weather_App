# 🌤️ Weather App

A simple weather application built with Python, Flask, JavaScript, HTML, and the Open-Meteo API.

The user can enter a city name and get its current weather information.

## ✨ Features

- Search weather by city name
- Press **Enter** to search
- Displays:
  - Temperature
  - Humidity
  - Wind speed
  - Feels-like temperature
  - Visibility
  - Precipitation
  - Snowfall
  - Weather condition
- Uses a geocoding API to convert city names into coordinates
- Uses Open-Meteo to retrieve current weather data
- Flask backend provides the weather data to the frontend

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **JavaScript**
- **HTML**
- **Open-Meteo API**
- **Git & GitHub**
